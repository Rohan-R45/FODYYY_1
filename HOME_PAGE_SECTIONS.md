## 🎭 Animation Sequence

### On Page Load
1. Navigation slides down (0.6s)
2. Hero content fades in (0.8s)
3. Floating icons start animating
4. Background blobs pulse

### On Scroll
1. Hero parallax effect
2. Features fade in (staggered)
3. Timeline draws
4. Restaurants zoom in
5. Testimonials slide in
6. Counters animate
7. CTA fades in
8. Footer appears

### On Hover
1. Navigation links underline
2. Buttons scale and glow
3. Feature cards lift
4. Restaurant images zoom
5. Social icons scale
6. Links change color
