## 🎨 Color Usage Guide

### Primary Gradient (Most CTAs)
```css
background: linear-gradient(to right, #FF6B35, #F7931E);
```

### Text Gradient (Headlines)
```css
background: linear-gradient(to right, #FF6B35, #F7931E, #FFC857);
background-clip: text;
```

### Dark Section Background
```css
background: linear-gradient(to bottom right, #1B1B1E, #374151);
```

### Light Section Background
```css
background: linear-gradient(to bottom right, #FFF8F0, #FFFFFF);
```

- 2-column feature grid

- 1-column stacked layout

- Simplified animations

## 🎭 Animation Timeline

### On Page Load
1. Hero badge fades in (0s)
2. Hero headline fades in (0.2s)
3. Hero subtext fades in (0.4s)
4. CTA buttons fade in (0.6s)
5. Floating icons start animation (0.8s)

### On Scroll
1. Features section fades in (staggered)
2. How It Works timeline animates
3. Restaurant cards zoom in
4. Testimonials slide in
5. Statistics counters animate
6. Final CTA fades in

### On Hover
- Cards lift up (-8px)
- Buttons scale (1.05x)
- Icons rotate (3deg)
- Shadows intensify
- Colors transition

## 🔧 Customization Points

### Easy to Change
1. **Colors**: Update `tailwind.config.js` foody colors
2. **Fonts**: Change font-display and font-body
3. **Content**: Edit text in Home.jsx
4. **Images**: Replace restaurant image URLs
5. **Testimonials**: Update testimonials array
6. **Statistics**: Change counter end values

### Requires More Work
1. Adding new sections
2. Changing layout structure
3. Modifying animation timing
4. Adding new components
5. Integrating with backend API

## 📊 Performance Metrics

### Target Metrics
- **First Contentful Paint**: < 1.5s
- **Largest Contentful Paint**: < 2.5s

- **Cumulative Layout Shift**: < 0.1
- **First Input Delay**: < 100ms

### Optimization Techniques
- Lazy loading images
- Code splitting
- GPU-accelerated animations
- Optimized bundle size
- Efficient re-renders
- Debounced scroll handlers
