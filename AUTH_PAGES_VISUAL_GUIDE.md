## 🎨 Design Elements Breakdown

### 1. **Animated Background**
```
Layer 1: Gradient (Cream → Orange → Yellow)
Layer 2: 3 Large Blobs (Orange, Yellow, Red with 30% opacity)
         - Moving in circular patterns
         - 20-30 second animation loops
Layer 3: Floating Food Emojis
         - 5 emojis positioned at corners and top
         - Continuous up/down + rotation animation
```

### 2. **Glassmorphism Card**
```
Properties:
- backdrop-blur-xl (Strong blur effect)
- bg-white/80 (80% white opacity)
- border: 1px solid orange-100
- shadow-2xl (Large shadow)
- rounded-3xl (Very rounded corners)
- padding: 2rem (mobile) to 2.5rem (desktop)
```

### 3. **User Type Selection Cards**
```
┌─────────────────┐  ┌─────────────────┐
│                 │  │                 │
│    🎓 Large     │  │    🏪 Large     │
│                 │  │                 │
│    Student      │  │  Restaurant     │
│   (Bold Text)   │  │  Owner          │
│                 │  │   (Bold Text)   │
│  Order food to  │  │  List your      │
│  your hostel    │  │  restaurant     │
│  (Small Gray)   │  │  menu           │
│                 │  │  (Small Gray)   │
└─────────────────┘  └─────────────────┘

Active State:
- Border: 2px solid orange-500
- Background: orange-50
- Icon: orange-500 color

Inactive State:
- Border: 2px solid gray-200
- Background: white
- Icon: gray-400 color
```

### 4. **Input Fields**
```
┌─────────────────────────────────────┐
│ 📧  your.email@iitt.ac.in          │
│     ↑                               │
│   Icon (absolute left)              │
└─────────────────────────────────────┘

States:
- Normal: Gray border, white background
- Focus: Orange border + orange ring (4px)
- Error: Red border + red ring (4px)
- Disabled: 50% opacity

With Icon:
- Icon positioned absolute left (16px from edge)
- Input padding-left: 48px (3rem)
- Icon color: gray-400
```

### 5. **Password Strength Meter**
```
Password strength: Strong
████████████████████████ 100%
↑                        ↑
Color (Red/Yellow/Green) Width (33%/66%/100%)

Criteria:
- Length ≥ 8 chars
- Length ≥ 12 chars
- Uppercase + Lowercase
- Numbers
- Special characters

Scoring:
- 0-2 criteria: Weak (Red, 33%)
- 3 criteria: Medium (Yellow, 66%)
- 4-5 criteria: Strong (Green, 100%)
```

### 6. **Submit Buttons**
```
┌─────────────────────────────────────┐
│  Sign In to FOODY              →    │
│  [Gradient: Orange → Red]           │
└─────────────────────────────────────┘

Properties:
- Width: 100%
- Padding: 14px vertical
- Background: linear-gradient(to right, #FF6B35, #DC2626)
- Text: White, semibold, 16px
- Border-radius: 12px
- Shadow: Large orange glow (50% opacity)

Hover State:
- Scale: 1.02
- Shadow: Extra large orange glow (60% opacity)

Tap State:
- Scale: 0.98

Loading State:
- Spinner animation (white border, orange top)
- Text: "Signing in..." / "Creating account..."
- Disabled: opacity 50%, cursor not-allowed
```

## 🎯 User Flow

### Login Flow:
```
1. User lands on /login
2. Sees animated background + floating foods
3. Card fades in with logo
4. Selects user type (Student/Restaurant)
5. Enters email
6. Enters password (can toggle visibility)
7. Optionally checks "Remember me"
8. Clicks "Sign In to FOODY"
9. Loading state shows
10. On success: Redirects to dashboard
11. On error: Shows error message with shake animation
```

### Register Flow:
```
1. User lands on /register (or clicks from login)
2. Sees animated background + floating foods
3. Card fades in with logo
4. Selects user type (Student/Restaurant)
5. Conditional fields slide in based on selection
6. Fills in all required fields
7. Password strength meter updates in real-time
8. Confirms password (validation checks match)
9. Checks "Accept Terms" checkbox
10. Clicks "Create Account"
11. Loading state shows
12. On success: Toast notification + redirect to dashboard
13. On error: Shows error messages with shake animation
```
